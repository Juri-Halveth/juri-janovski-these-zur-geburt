# HALVETH!!! · These zur Geburt / Thesis on Birth

**Concise project guide · EN / RU**

A public thesis presented as a reproducible PDF and Python program. Its central question connects a birthing woman’s control over her environment with available midwifery support and clinical safety. The README documents the editorial naming edition and the historical release PDF.

This is a research and presentation artifact. Its existence, PDF build or private work certificate does not establish a clinical outcome or confer a professional qualification. Content, code, fonts and dependencies have their own recorded licence terms.

This manually edited guide summarizes the audited source. The original technical documentation remains the reference for commands, build requirements, exact versions and detailed evidence.
