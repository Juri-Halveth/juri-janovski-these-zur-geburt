# HALVETH!!! · These zur Geburt / Thesis on Birth

**Краткий путеводитель по проекту · EN / RU**

Публичная исследовательская работа в виде воспроизводимого PDF и программы Python. Её основной вопрос связывает контроль рожающей женщины над своей средой с доступной помощью акушерки и клинической безопасностью. README описывает редакцию публичного имени и исторический PDF выпуска.
